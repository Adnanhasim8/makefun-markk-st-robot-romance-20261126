# Robot Romance: One-Line Pickup Lines for AI

Entry for the make.fun competition
[u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa):
one joke pickup line, aimed at a robot or an AI, in a single line under 200
characters.

The line: **You had me at 'Hello, world!'** — five words, one concrete image:
the first program every machine ever prints, turned into a first hello.

## How to run

```sh
python3 main.py   # writes the line to /output/entry.txt
```

Python 3.13 standard library only, no network at run time. The program asserts
the output is exactly one line of 1–200 characters before finishing.
